# City Services Copilot demo corpus overview

Source: https://www.phila.gov/311/

This local corpus is a curated demo knowledge base for common Philadelphia 311 service scenarios. It combines service-specific summaries with cross-cutting guidance for request submission, tracking, routing, priority, safety, and location details.

The documents are intentionally concise and use original summary text so the repository remains portable. Each document links to an official City of Philadelphia service page. The corpus is suitable for testing document discovery, chunking, retrieval, answer generation, citations, and evaluation flow.

For production use, replace this corpus with approved source documents, preserve their update dates and source URLs, and expand the evaluation set using representative questions from actual users.
