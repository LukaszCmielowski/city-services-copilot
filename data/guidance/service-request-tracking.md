# Track a 311 service request

Source: https://www.phila.gov/311/

Keep the service-request number after submission. It can be used to review the request record and its status through the 311 service-request tracker. A status shows the state of the request, not a guarantee that a particular action will occur at a particular time.

Common request states include received, in progress, completed, and closed with an explanation. A request can be closed because work was completed, the condition could not be verified, responsibility belongs to another organization, or the issue does not qualify for the selected service.

If a condition changes materially, provide the new information through the appropriate channel instead of repeatedly submitting the same report.
