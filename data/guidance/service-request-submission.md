# Submit a 311 service request

Source: https://www.phila.gov/311/

Use a 311 service request for non-emergency city services and neighborhood conditions. Select the service category that most closely matches the issue, then provide the best available location and a concise description of what was observed.

Useful request details include an intersection, block, landmark, direction of travel, or pole number when applicable. Photos can help describe a condition when they can be taken safely. A service request should describe the physical issue rather than speculate about who caused it.

One clear request is preferable to multiple duplicate submissions. The city uses the request record to route work, communicate status, and identify patterns in service demand.
