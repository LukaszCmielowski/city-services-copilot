# Request vacant lot cleanup

Source: https://www.phila.gov/services/trash-recycling-city-upkeep/report-a-problem-with-trash-recycling-or-city-upkeep/request-a-vacant-lot-cleanup/

Use 311 to request attention for a vacant lot that is overgrown, covered with trash, or otherwise neglected. Include the lot location and describe the condition that needs review.

The City’s Vacant Lot Program can inspect the lot for compliance with property-maintenance rules. If a violation is found, the owner receives notice and an opportunity to correct it. City cleanup may follow when the owner does not correct a confirmed violation; request timing can include inspection and notice steps.
